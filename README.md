# ITパスポート学習Webアプリ

ITパスポート試験の学習を支援するWebアプリケーション。基礎知識のインプットから、演習・苦手克服・本番形式の実践演習までを一通り行える学習サイクルをWeb上で完結できることを目指して作成した個人開発のポートフォリオ作品です。

## 概要

- 基礎知識をジャンル別に学び、演習問題で知識を確認し、回答履歴から苦手ジャンルを判定して重点的に学習し、最後に本番形式の実践演習で仕上げる、という学習の一連の流れをアプリ内で完結できる
- ログイン不要ですぐに使い始められる「ゲスト利用」に対応しつつ、会員登録すればゲスト時代の学習履歴をそのまま引き継げる
- 教材データ(基礎知識・問題)はExcelで管理し、アプリ起動時に自動でDBへ取り込む

## 主な機能

| 機能 | 内容 |
|---|---|
| 基礎知識学習 | IPA公式シラバスVer.6.5の63項目と1対1対応する63単元をジャンル別に学習 |
| 用語集 | 基礎知識の重要語句(440語)を用語単位で自動リンク化し、一覧・検索・定義参照ができる。ジャンル別/50音順の並び替えに対応 |
| 演習問題 | 25/50/100問/エンドレスから選択。1問ごとに正誤・選択肢別の解説を表示 |
| 苦手克服 | 回答履歴から正答率(得意/普通/苦手/かなり苦手)を判定し、苦手ジャンルほど出題されやすい重み付き抽選で出題 |
| 実践演習 | 大分類比率(ストラテジ35:マネジメント20:テクノロジ45)で100問出題、制限時間120分、回答中は正誤非表示、終了後にまとめて採点 |
| ホーム | 全体正答率・苦手ジャンルの一覧・各機能への導線 |
| ゲスト利用/会員登録 | 未ログインでも全機能を利用可能。会員登録するとゲスト時代の履歴を引き継いだままアカウント化される |
| パスワードリセット | メール経由でのパスワード再設定(トークンは30分失効・使い捨て、列挙攻撃対策済み) |
| アカウント削除 | 登録ユーザーはパスワード確認のうえ、ゲストは即時に、全データを完全削除できる |

## 設計のポイント

- **ゲストと会員を同じ`users`テーブルで管理**: `user_type`(GUEST/REGISTERED)で区別し、ゲストが会員登録すると同じ行をREGISTEREDへ書き換えるだけで学習履歴を引き継げる設計にした
- **選択肢の正規化**: Excel上は`choice_1`〜`choice_4`の列だが、DBでは`question_choices`テーブルに正規化し、単一選択・複数選択を同じロジックで判定できるようにした
- **Excelを正として自動反映**: 教材データはExcelで管理し、アプリ起動時にIDをキーにUPSERTする。再取込みしても重複しない
- **ゲストデータの自動削除**: 最終アクセスから30日操作のないゲストアカウントは定期ジョブで自動削除し、履歴もCASCADE削除される。会員は削除されない
- **セキュリティ**: BCryptによるパスワードハッシュ化、CSRF対策、パスワードリセットトークンの列挙攻撃対策・使い捨て化・連投防止など、一通りの基本対策を実施

設計の詳細は [docs/db-design.md](docs/db-design.md)、教材データの仕様は [docs/excel-format.md](docs/excel-format.md) を参照。

## ローカルでの動かし方

### 前提

- Java 21
- PostgreSQL(ローカルで稼働しているもの、または`docker-compose.yml`を利用)

### 手順

```bash
# PostgreSQLをdocker-composeで起動する場合
docker compose up -d

# アプリ起動(Maven Wrapper同梱のためMavenのインストール不要)
./mvnw spring-boot:run
```

起動すると `http://localhost:8080` でアクセスでき、初回起動時にExcel(`src/main/resources/data/study-materials.xlsx`)の内容が自動でDBへ取り込まれる。

接続先DBはデフォルトで `localhost:5432 / db=itpassport / user=itpassport / password=itpassport` を想定(`application.properties`参照)。環境変数`PGHOST`/`PGPORT`/`PGDATABASE`/`PGUSER`/`PGPASSWORD`で上書き可能。
